# Portal Management System

A robust console-based application written in C designed to simulate a university or school portal. It manages core administrative tasks including student registration, course enrollment, and secure record keeping using file I/O operations.

## 🌟 Key Features
* **Secure Access:** Login system to authenticate users before granting access to portal functionalities.
* **Student Management:** Add, view, and manage student profiles and records dynamically.
* **Course Administration:** Maintain a catalog of available courses and track student enrollments.
* **Data Persistence:** Utilizes C file handling to permanently store and retrieve data from `students.txt` and `courses.txt`.
* **Interactive CLI:** A user-friendly command-line interface tailored for easy navigation and data entry.

## 🛠️ Tech Stack
* **Language:** C
* **Concepts:** Structs, Pointers, File Handling (`<stdio.h>`), and String Manipulation (`<string.h>`).
* **Environment:** Compatible with Windows/Linux console environments.

## 📁 Repository Structure
* `portalmanagement.c`: The main source code containing the logic for user authentication, menu navigation, and file operations.
* `students.txt`: The text file acting as the database for student records.
* `courses.txt`: The text file acting as the database for course listings and enrollments.
* `portalmanagement.exe`: The compiled Windows executable file ready for testing.
